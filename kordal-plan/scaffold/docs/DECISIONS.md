# Decisions

Small, non-obvious choices that are not architecture: why a library, a default, a workaround or a rejected approach was picked. One dated line each, newest last, written in the change that made the choice. An architecture decision is an [ADR](adr/README.md) instead.

Format: `- YYYY-MM-DD: <choice>, because <reason>. Rejected: <alternative> (<why>). (<PR, task or plan>)`
